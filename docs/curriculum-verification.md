This document provides a line-by-line verification of the academic curriculum data integrated into the CPU College of Computer Studies web portal against the four official curriculum checklist PDFs located in `docs/reference-materials/`.

   - `BSIT-Curriculum-Checklist-2024.pdf` (4 Pages)

   - `DMIA-Curriculum-Checklist-2024.pdf` (5 Pages)

2. **Signature/Endorsement Verification:**
   - *Observation:* The checklist PDFs contain official **typed endorsement and approval blocks** (specifying signatories, titles, and academic degrees), with blank underline fields for handwritten signatures and dates. They do **not** contain embedded raster/scanned handwritten signatures. All documentation has been updated to describe these as typed endorsement/approval lines rather than signed documents.
3. **Zero Invention Standard:** Every course code, course title, lecture/laboratory hour allocation, unit credit, prerequisite, and track group matches the source checklist.
