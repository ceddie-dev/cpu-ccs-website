# CPU College of Computer Studies — Reference Curriculum Materials

This directory stores the official curriculum checklists for the College of Computer Studies, Central Philippine University, effective Academic Year 2024–2025.

> **Note on Checklist Endorsement Blocks:** All four checklists feature official typed endorsement and approval blocks with blank signature underlines. They do not contain embedded digital or scanned signatures.
